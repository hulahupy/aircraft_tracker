# Aircraft Tracker

Учебный проект на Python + Poetry + PostgreSQL. Получает географические bounding box стран через Nominatim, запрашивает состояния воздушных судов OpenSky, сохраняет наблюдения в PostgreSQL и предоставляет аналитические методы `DBManager`.

## Что внутри

- `aircraft_tracker/api_client.py` — запросы к Nominatim и OpenSky.
- `aircraft_tracker/database.py` — подключение и сохранение данных в PostgreSQL.
- `aircraft_tracker/db_manager.py` — пять методов аналитики.
- `aircraft_tracker/config.py` — список 10 стран и настройки.
- `aircraft_tracker/schema.sql` — схема БД.
- `aircraft_tracker/main.py` — точка входа.
- `.env.example` — шаблон настроек подключения.

## Требования

- Python 3.11+
- Poetry
- PostgreSQL

## Установка в PyCharm

1. Распакуйте архив и откройте папку `aircraft_tracker` как проект в PyCharm.
2. Убедитесь, что выбран Python-интерпретатор из Poetry-окружения.
3. В терминале проекта выполните:

   ```bash
   poetry install
   ```

4. Создайте базу данных PostgreSQL. Например, через `psql`:

   ```sql
   CREATE DATABASE aircraft_db;
   ```

5. Скопируйте `.env.example` в `.env` и заполните параметры своей БД.
6. Запустите программу:

   ```bash
   poetry run python -m aircraft_tracker.main
   ```

   Или используйте команду:

   ```bash
   poetry run aircraft-tracker
   ```

## Что делает запуск

1. Создаёт таблицы, если их ещё нет.
2. Получает границы десяти стран через Nominatim.
3. Для каждой страны запрашивает OpenSky по bounding box.
4. Сохраняет страну и наблюдения воздушных судов.
5. Выводит количество записей по странам, среднюю скорость и пример поиска позывного `ACA`.

## Важные ограничения

- Bounding box — прямоугольник, который не совпадает с точной границей страны. Поэтому запрос может включать самолёты над соседними странами или морем; один самолёт может попасть в несколько стран. Для строгой географической принадлежности нужны полигоны границ и point-in-polygon.
- OpenSky может ограничивать анонимные запросы или требовать OAuth2. Если возникает `401`, `403` или `429`, проверьте текущую документацию OpenSky и добавьте OAuth2 client ID/secret в `.env`.
- Nominatim — публичный сервис: клиент делает паузу между запросами, использует описательный `User-Agent`; не запускайте частые циклические сборы.
- Таблица `aeroplanes` хранит историю наблюдений: при повторных запусках добавляются новые строки.
- `velocity` хранится в метрах в секунду. `get_avg_speed()` считает среднее по наблюдениям в воздухе с известной скоростью, а не по уникальным самолётам.
- Для упрощения список стран и их bounding box загружается при запуске; географические данные не являются навигационной гарантией.

## Методы DBManager

- `get_countries_and_aeroplanes_count()` — список стран и число наблюдений через `LEFT JOIN`.
- `get_all_aeroplanes()` — все наблюдения воздушных судов.
- `get_avg_speed()` — средняя скорость в м/с для воздушных судов в воздухе.
- `get_aeroplanes_with_higher_speed()` — наблюдения со скоростью выше средней.
- `get_aeroplanes_with_keyword(keyword)` — поиск по подстроке позывного без учёта регистра.
